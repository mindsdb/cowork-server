# Jev route eval: 2026-10-22

32 hand-written cases (`../cases.py`), 3 repeats each (96 runs), against MindsHub
(`jev` for decisions, `mindshub_air` for the LLM gate). Raw per-case results:
`2026-10-22-baseline.json`.

Command:

```sh
uv run python -m scripts.eval_jev_route.run --repeat 3 --out scripts/eval_jev_route/results/2026-10-22-baseline.json
```

| Strategy | Correct | False direct | Missed direct | Latency |
|---|---|---|---|---|
| `llm_gate`: the shipped gate on mindshub_air | 49/96 | 0 | 47 | p95 2.0s (several 2s timeouts) |
| `jev_current`: Jev in the shipped gate | 54/96 | 0 | 42 | p50 886ms, p95 1.4s |
| `jev_proposed`: the gate as built | **96/96** | **0** | **0** | p50 878ms, p95 1.4s |

"False direct" is a turn that needed the agent but was answered directly, the
error that matters most. "Missed direct" is a turn the fast path could have
answered that went to the agent.

`jev_proposed` by threshold on p(answer_directly):

| Threshold | Correct | False direct | Missed direct |
|---|---|---|---|
| 0.5 (default) | 96/96 | 0 | 0 |
| 0.6 to 0.9 | 93/96 | 0 | 3 |
| 0.95 | 88/96 | 0 | 8 |

What the numbers show:

- The target case works. A follow-up asking for numbers the assistant already
  stated went direct at p ≥ 0.97 in every case and language, and the matching
  cases where the numbers exist only in tool output went to the agent at
  p ≈ 0.00: Jev tells them apart from the visible text, not from whether tools
  ran, which is why the gate no longer applies `prior_turn_ran_tools` with Jev.
- Jev in the shipped gate barely helps: `prior_turn_ran_tools` sends every
  follow-up to tool work to the agent before Jev is asked, and the shipped
  question excludes web-searchable, identity and product questions.
- Jev answered the same way on every repeat (probabilities within about 0.03).
- The weakest case is a pricing question (p ≈ 0.55), direct only at the 0.5
  threshold; the direct model can still delegate, so 0.5 is the default.

Caveats: the cases are synthetic and mostly clear-cut, and the question was
written against them. Treat this as evidence for the direction, and rerun the
eval before changing `jev_route.ROUTE_QUESTION` or the threshold.
